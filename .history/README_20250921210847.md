# 🤖 Voice Bot - AI Interview Assistant

A professional voice-enabled chatbot for AI Agent Team interviews. This application uses Streamlit for the web interface, Google's Gemini AI for intelligent responses, and multiple voice input methods for maximum compatibility.

## 🚀 Features

- **Multiple Voice Input Methods**: Live recording, file upload, web recorder
- **Text Input**: Type questions if you prefer
- **AI-Powered Responses**: Uses Gemini AI to respond as job candidate
- **Text-to-Speech**: Hear responses spoken aloud (when available)
- **Professional UI**: Clean, modern Streamlit interface
- **Cross-Platform**: Works on Windows, Mac, Linux, and cloud deployments
- **No-Dependency Fallbacks**: Works even when audio libraries aren't available

## 🛠️ Technology Stack

- **Frontend**: Streamlit
- **AI Model**: Google Gemini Pro API
- **Speech Recognition**: Google Speech Recognition API
- **Text-to-Speech**: pyttsx3 (optional)
- **Audio Processing**: Multiple options with fallbacks
- **Environment Management**: python-dotenv

## 📋 Prerequisites

- Python 3.8 or higher
- Gemini API key (free from Google AI Studio)
- Internet connection for speech recognition and AI responses
- Microphone access for live voice input (optional)

## 🔑 API Key Setup
1. Visit [Google AI Studio](https://makersuite.google.com/app/apikey)
2. Sign in with your Google account
3. Create a new API key
4. Copy the API key

### Step 4: Configure Environment Variables
1. Open the `.env` file in the project root
2. Replace `your_gemini_api_key_here` with your actual Gemini API key:
```env
GEMINI_API_KEY=your_actual_api_key_here
```

### Step 5: Run the Application
```bash
streamlit run app.py
```

The application will open in your default web browser at `http://localhost:8501`

## 🔍 Technical Details

### Voice Processing Pipeline
1. **Audio Capture**: Uses PyAudio to capture microphone input
2. **Speech-to-Text**: Google Speech Recognition converts audio to text
3. **AI Processing**: Gemini AI generates contextual responses
4. **Text-to-Speech**: pyttsx3 converts responses back to audio

## 🐛 Troubleshooting

### Common Issues

**Microphone not working:**
- Check browser permissions for microphone access
- Ensure your microphone is not being used by other applications
- Try refreshing the page

**API Key errors:**
- Verify your Gemini API key is correct in the `.env` file
- Check that your API key has the necessary permissions
- Ensure you haven't exceeded API rate limits

**PyAudio installation issues:**
- On Windows: Use `pipwin install pyaudio`
- On macOS: Install with `brew install portaudio` then `pip install pyaudio`
- On Linux: Install with `sudo apt-get install python3-pyaudio`

**Speech recognition not working:**
- Check your internet connection
- Speak clearly and at a moderate pace
- Ensure minimal background noise
